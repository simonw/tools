View and visualize GeoJSON data on an interactive OpenStreetMap with customizable styling options. Paste GeoJSON objects (Feature, FeatureCollection, or Geometry) into the editor, adjust fill color and opacity, and render the features directly on the map. Export the rendered map as a PNG image with proper attribution included: choose a resolution (1× to 4×, with higher resolutions built from deeper-zoom OpenStreetMap tiles since OSM does not serve retina tiles), then preview the result in a modal where you can copy the image to the clipboard or download it with the file size shown on the button.
