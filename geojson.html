OpenStreetMap has no retina tiles, so higher resolutions load tiles from deeper zoom levels for sharper detail. Labels stay the same pixel size, so they look smaller in the export. The export is centred on the current map view at the current zoom.

Paste GeoJSON, then render it.

Supports GeoJSON Geometry, Feature, and FeatureCollection objects. Coordinates use longitude, latitude order. Add more shapes to overlay several GeoJSON objects, each with its own colour and opacity — later shapes are drawn on top. Instead of pasting, load a shape from a GitHub Gist or any JSON URL served with CORS headers; loaded URLs, colours, opacities, the map view, and PNG export settings are saved in this page's URL fragment so the map can be shared and renders automatically when opened.
