    How it works, dependencies & privacy limits

    This single HTML file decodes a JPEG, PNG or WebP locally, with the browser applying EXIF orientation. It uses MediaPipe’s short-range BlazeFace model on the whole image and overlapping crops. “Find smaller faces” scans a denser set of crops. Detection locates faces; it does not identify people. Very small, turned, obscured or otherwise difficult faces may be missed.

    Redaction uses an embedded three-pass separable box blur on an opaque, bounded-resolution patch, or a solid fill. Preview and export use the same routine. JPEG exports are flattened onto white; PNG preserves transparency outside covered regions. Animated PNG and WebP inputs are rejected. HEIC, RAW and SVG are not supported. Large images require an explicit resolution choice.

    Export creates a new sRGB canvas encoding, then removes every JPEG APP/COM segment, or every PNG chunk except IHDR, PLTE, tRNS, IDAT and IEND. It discards trailing bytes, verifies that only permitted structures remain, checks PNG chunk checksums and decodes the result to confirm its dimensions. This removes EXIF, XMP, IPTC, comments, embedded thumbnails, profiles and other original metadata containers; it does not remove information visible in the picture or promise forensic anonymity. The output uses a neutral filename. Color profiles and HDR information are not preserved.

    Dependencies are pinned: @mediapipe/tasks-vision 0.10.21 (Apache-2.0), JavaScript and WebAssembly from jsDelivr; BlazeFace short-range float16 model, version 1 from Google. No analytics, photo uploads or persistent photo storage are implemented. The browser may cache dependency files. CDN JavaScript runs with page privileges: pinning versions and restricting connections are not a complete supply-chain defense. Audit and self-host dependencies for high-risk photos.

    Open the file in a modern browser while online to load the detector. If local-file security restrictions prevent loading, serve the containing folder with python3 -m http.server 8000, then open http://localhost:8000/photo-scrubber.html. If detection is unavailable, manual blur and solid cover still work. “Clear” releases this page’s photo references, not a secure erase of browser memory.

    Keyboard: D to draw, V to select; arrow keys move a selected box, Shift + arrows move 10 pixels; Delete removes it; Ctrl/⌘ Z undoes; Ctrl/⌘ Shift Z redoes; Escape cancels a drag. Select a region in the list to edit its exact coordinates.
