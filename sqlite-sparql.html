SPARQL in SQLite

A playground for sparqlite, a SQLite extension written in Rust that stores RDF in SQLite tables and runs SPARQL 1.1 queries and updates against them from SQL. Here the extension is compiled to WebAssembly and linked into SQLite's official WASM build, so everything runs in your browser. The example data is a knowledge graph of 94 programming languages: pick an example, or write your own query.

The store

The database is an ordinary SQLite file (RDF in the rdf_quad and rdf_term tables). A downloaded copy works with the native extension too: sqlite3 playground.sqlite '.load ./libsparqlite' "SELECT sparql_query('ASK {?s ?p ?o}')"

About the example data

From the sparqlite tutorial:

  • languages.ttl (default graph): 94 computer languages, 117 people and 40 organisations: first-appeared years, designers, developers, influences, paradigms (a small rdfs:subClassOf hierarchy), typing, file extensions and some homepages. Real, checked against the English Wikipedia infoboxes. Labels in English, French, German, Spanish and Japanese.
  • survey.trig: fictional developer surveys for 2025 and 2026 and editorial reviews, each in its own named graph.
  • job_postings.sql: an ordinary SQL table of 300 fictional job adverts, for joining SPARQL results with relational data.
