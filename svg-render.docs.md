SVG to PNG, JPEG or WebP renders pasted SVG code, dropped or opened SVG files, or an SVG loaded from a `?url=` parameter into a bitmap entirely in the browser. You can choose the output format, quality for lossy formats, width, padding, and background color or transparency, then review a live preview with its pixel dimensions and file size, download the image, or copy a base64 image tag. The SVG source is saved in the URL hash so work can be shared or restored, and enabling transparency switches a JPEG output to PNG. Where the browser cannot encode WebP natively, such as Safari, the page loads a WebAssembly WebP encoder from a CDN the first time WebP is requested.
