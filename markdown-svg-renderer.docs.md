Renders markdown with a live preview from pasted text, a raw URL, or a GitHub Gist loaded through a `?url=` query parameter, and older `#url=` links redirect to that form. Standard formatting, tables, code blocks, and linkable heading anchors are supported, along with fenced SVG blocks that offer tabbed Rendered, PNG, JPEG, WEBP, AVIF, and Code views, plus an MP4 tab for animated SVGs encoded with ffmpeg.wasm. HTML blocks run in a sandboxed iframe with scripts allowed but resource loading limited to a few CDNs, and a toggle switches between the split editor and a full-screen viewer.
